# EditPDF Web

EditPDF, PDF dosyalarını birleştirme, bölme, sıkıştırma, şifreleme, dönüştürme, filigran ekleme ve sayfa yönetimi gibi işlemleri kolayca yapmanızı sağlayan modern bir web uygulamasıdır.

## Özellikler
- PDF birleştirme ve bölme
- PDF sıkıştırma
- PDF şifreleme/şifre kaldırma
- PDF'den Word/Excel/JPG'e ve tersi dönüşümler
- Filigran ekleme
- Sayfa silme, döndürme, sayfa sayısı öğrenme

## Kurulum
1. Gerekli bağımlılıkları yükleyin:
   ```bash
   pip install -r requirements.txt
   ```
2. Uygulamayı başlatın:
   ```bash
   streamlit run app.py
   ```

## Notlar
- Tüm kod ve işlevler tamamen web tabanlıdır, masaüstü PDFToolKit ile hiçbir bağımlılığı yoktur.
- Logoları ve görselleri dilediğiniz gibi değiştirebilirsiniz.
